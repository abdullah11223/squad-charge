# زحف الفرقة (Squad Charge)

لعبة "crowd runner shooter" ويب ثلاثية الأبعاد — جيشك يتحرك تلقائيًا للأمام على طريق ثلاثي الأبعاد وأنت تتحكم بحركته يمين/يسار بالسحب، تمر ببوابات فائدة/ضرر، تشتبك مع أعداء بمؤثرات إطلاق نار وانفجارات، وتكسر عوائق، وصولًا لخط النهاية عبر ٢٥ مرحلة.

مبنية بـ [Three.js](https://threejs.org) (رسم ثلاثي الأبعاد حقيقي) و[GSAP](https://gsap.com) (حركة/مؤثرات) — كلاهما يُحمّلان عبر CDN كوحدات ES مباشرة (import map)، بدون أي خطوة بناء (build step)، تشتغل مباشرة من `index.html`. الواجهات (القائمة، المستويات، المتجر، النتيجة) HTML/CSS عادي.

## التشغيل محليًا

أي سيرفر ستاتيك يكفي، مثلًا:

```bash
python3 -m http.server 8080
```

بعدها افتح `http://localhost:8080` بالمتصفح (أو من الجوال على نفس الشبكة).

## هيكلة المشروع

```
squad-charge/
  index.html
  src/
    main.js
    styles.css       تنسيق كل شاشات الواجهة
    ui/
      screens.js      المنيو، اختيار المستوى، المتجر، شاشة النتيجة
    game/             طبقة الرسم ثلاثي الأبعاد (Three.js)
      GamePlay.js       المتحكم الرئيسي بمشهد اللعب
      CharacterFactory.js  شخصيات chibi منخفضة التفاصيل مبنية من أشكال هندسية
      RoadBuilder.js      الطريق والحواجز الجانبية
      ArmyMesh.js / EnemyWaveMesh.js / GateMesh.js / ObstacleMesh.js / FinishMesh.js
      VFX.js            ومضات إطلاق، انفجارات، شرر عملات، اهتزاز شاشة
      SpriteText.js     نصوص/أيقونات عائمة تواجه الكاميرا
    systems/          مولّد المراحل، معادلات القتال، الحفظ (منطق بحت، بدون أي محرك رسوم)
    config/           جدول الأسلحة، إعدادات الصعوبة، أسعار المتجر
  assets/
```

## النشر على GitHub Pages

1. `git push` للمستودع على فرع `main`.
2. من إعدادات المستودع: **Settings → Pages** → اختر المصدر فرع `main` والمسار `/ (root)`.
3. بعد دقيقة أو دقيقتين يصير عندك رابط مباشر تقدر تفتح منه اللعبة من أي جوال.

## ملاحظات

- كل الشخصيات والمجسمات (chibi soldiers، الطريق، البوابات، العوائق) مولّدة بالكود عبر أشكال Three.js الهندسية الأساسية — ما فيه أي نماذج أو أصول أو حقوق ملكية خارجية.
- التقدم (العملات، المستويات المفتوحة، النجوم، ترقيات المتجر) يُحفظ في `localStorage` بالمتصفح.
- كل مرحلة تُولّد بشكل ثابت (deterministic) من رقم المرحلة — نفس المرحلة تعطي نفس التخطيط كل مرة.
- بعد أول تجربة لعب، منحنى الصعوبة بالمرحلة ١ يبدو قاسي شوي (ممكن تخسر من أول اشتباكين) — القسم ٦ بالمواصفات نفسه يقول نعدّل الأرقام بعد أول نسخة قابلة للعب حسب الإحساس الفعلي.
