# زحف الفرقة (Squad Charge)

لعبة "crowd runner shooter" ويب — جيشك يتحرك تلقائيًا للأمام وأنت تتحكم بحركته يمين/يسار بالسحب، تمر ببوابات فائدة/ضرر، تشتبك مع أعداء، وتكسر عوائق، وصولًا لخط النهاية عبر ٢٥ مرحلة.

مبنية بـ [Phaser 3](https://phaser.io) عبر CDN — بدون أي خطوة بناء (build step)، تشتغل مباشرة من `index.html`.

## التشغيل محليًا

أي سيرفر ستاتيك يكفي، مثلًا:

```bash
python3 -m http.server 8080
```

بعدها افتح `http://localhost:8080` بالمتصفح (أو من الجوال على نفس الشبكة).

## هيكلة المشروع

```
squad-charge/
  index.html
  src/
    main.js
    scenes/        شاشات اللعبة (قائمة، لعب، متجر، ...)
    entities/       الجيش، الأعداء، البوابات، العوائق
    systems/        مولّد المراحل، معادلات القتال، الحفظ
    config/         جدول الأسلحة، إعدادات الصعوبة، أسعار المتجر
  assets/
```

## النشر على GitHub Pages

1. `git push` للمستودع على فرع `main`.
2. من إعدادات المستودع: **Settings → Pages** → اختر المصدر فرع `main` والمسار `/ (root)`.
3. بعد دقيقة أو دقيقتين يصير عندك رابط مباشر تقدر تفتح منه اللعبة من أي جوال.

## ملاحظات

- كل الرسومات (شخصيات ستيك فيقر) مولّدة بالكود عبر Phaser Graphics — ما فيه أي أصول أو حقوق ملكية خارجية.
- التقدم (العملات، المستويات المفتوحة، النجوم، ترقيات المتجر) يُحفظ في `localStorage` بالمتصفح.
- كل مرحلة تُولّد بشكل ثابت (deterministic) من رقم المرحلة — نفس المرحلة تعطي نفس التخطيط كل مرة.
